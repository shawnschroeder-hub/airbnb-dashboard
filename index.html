Deal Analyzer

Vacation Rental Deal Analyzer 5.0 results

One filled workbook per 1%+ property (folder: Agent OS › 01 Projects › Airbnb Acquisitions › Analyzers). Financed at 80% LTV / 30-yr / 7.0% APR. Sorted by cash-on-cash. Basis since 2026-07-26 (Shawn's standing rule — every analyzer, every time): nightly rates come from AirDNA market data verified against live Airbnb comps for the property's actual class. Headline market ADRs are set by amenity properties (lakefront, pools, hot tubs, arcade rooms); ordinary homes book at roughly half those averages, and these numbers reflect that. Occupancy = AirDNA market average, i.e., a full-time, well-run listing. Watseka rows: no local comps exist — regional floor rates, STR demand unproven. Board yields remain the separate conservative revenue-average screen. Rentalizer per address before any offer.

Honesty system

  • Turnkey-verified — listing documents a recent full renovation
  • Condition unverified — confirm with agent
  • Flagged — as-is / rehab-priced / auction / code issues, stated verbatim
  • Cash only — verified wording; "cash or conventional" doesn't count

Database, not a report

Properties are keyed by address and remembered — new screens only research what's new, and every property keeps first-seen / last-seen dates and price history so price-change watching can be added later. Favorites and notes live in C:\Users\shawn\Code\airbnb-hq\data.
